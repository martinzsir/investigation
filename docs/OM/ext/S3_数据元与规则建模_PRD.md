## 六、功能详情

### F1 数据元编辑器（1.0 人日）

**F1.1 字段表单**

| 字段 | 控件 | 校验 |
|---|---|---|
| `name` | 文本框，已有项**不可改** | `^DE_[A-Z_]+$` |
| `type` | 下拉 | 与对象属性类型同一枚举 |
| `length` | 数字 | 正整数 |
| `format` | 文本框 + **试匹配**按钮 | 合法正则 |
| `checksum` | 下拉（含空） | 现有校验算法枚举 |
| `sensitive` | 勾选框 | — |
| `mask` | 下拉（含空） | `none` / `partial` / `full` |
| `clean_rule` | 下拉（含空） | 现有 `clean_ops` 子集 |

**F1.2 format 试匹配**（P1 的解法）

- 输入样例值 → 实时显示「✅ 命中」/「❌ 未命中」
- 提供 2–3 个预置样例（身份证/手机号/金额各一）
- 🔴 正则非法时**阻止保存**并提示位置

**F1.3 名称不可改**（对应 S2 R1）

`name` 被对象属性 `data_element` 引用，改名 = 隐式断链且不报错。

### F2 数据元三层视图（0.5 人日）

**F2.1 三层切换**

顶部三个 tab：全域 / 行业 / 本案件，各显示条目数。

**F2.2 覆盖关系可视化**（P2 的解法，★ 本阶段用户价值最高点）

- 案件层覆盖上层时，条目标「被覆盖」并显示**差异字段**
- 悬停显示「上层值 → 本层值」

**F2.3 只读性**

- 全域层 / 行业层条目：仅本体管理员可改（`is_ontology_admin=1` 且 rank ≥ 偏将）
- 案件层：rank ≥ 偏将可改
- 非管理员看上层条目时，表单**只读** + §8.4 提示

### F3 规则编辑器（1.5 人日）

**F3.1 表单化字段**

| 原 JSON 结构 | 控件 |
|---|---|
| 规则名 | 文本框（已有项不可改） |
| 描述 | 多行文本 |
| `jian_types` | **五个勾选框**（内间/死间/因间/反间/生间） |
| 参数表 | 可增删行（名称 / 类型 / 默认值） |
| 手册 | 多行文本 |

> **间类用勾选框**是明确收益：现有 `jian_types` 是字符串数组，手填易拼错（如「生间」写成「生閒」），且不校验是否在五间内。

**F3.2 保留既有能力**

- 规则列表、危险确认弹窗、**真入队 RESCAN**（`rule_workshop.py:191`）**全部保留不回退**
- 仅替换右侧编辑区

### F4 函数声明可视化（0.5 人日）

- `functions.schema.json` 已存在，**成本最低**
- 展示：名称 / 参数声明 / 返回类型 / 依赖对象
- 本期**只读**（无写路由）

| # | 红线 | 依据 | 违反后果 |
|---|---|---|---|

## 八、文案规则

### 8.1 通用规则

- 三层标识用图标 + 文字，不只靠颜色
- 覆盖关系说「被本案件覆盖」，不说「冲突」（后者像错误）
- 保存反馈不承诺「自动触发」（沿用 S0 R3）

### 8.2 覆盖关系提示（F2.2）

> 「本数据元在**全域层**已定义，本案件已覆盖其 `mask` 字段：
> 全域层 `full` → 本案件 `partial`」

### 8.3 试匹配结果（F1.2）

| 情况 | 文案 |
|---|---|
| 命中 | 「✅ 命中」 |
| 未命中 | 「❌ 未命中 —— 请检查正则或样例值」 |
| 正则非法 | 「🔴 正则非法：第 7 位缺少 `)`。保存已被阻止」 |

### 8.4 只读提示（F2.3）

> 「🔒 全域层数据元仅本体管理员可修改。你正在以只读方式查看。」

### 8.5 规则保存文案（F3.2）

> 「规则已保存，**已提交 RESCAN 重跑**（可在任务中心查看进度）」

> 🔴 此文案**仅在本阶段确实入队时使用**。若后续改动导致不再入队，必须同步改文案。

### 8.6 未知字段提示（R5）

> 「本数据元有 1 个界面未覆盖字段（`alias`），已原样保留。」

## 九、状态机

### 9.1 数据元编辑器

```
加载中 → 就绪 / 空 / 无权限
就绪 → 选中条目 → 编辑中（dirty）→ 保存中 → 已保存 / 保存失败
                              └→ 取消 → 就绪（丢弃变更）
```

| 状态 | 说明 |
|---|---|
| `加载中` | 读三层数据元 |
| `空` | 该层无数据元 |
| `无权限` | 非管理员看上层（**只读态**，非阻断） |
| `编辑中（dirty）` | 有未保存变更 |
| `保存中` | 校验 + 写临时目录 + `load_pack` 验证 |
| `已保存` | 落盘成功 |
| `保存失败` | 校验失败（正则非法 / 重名 / 装载失败） |

### 9.2 正则试匹配状态

| 状态 | 说明 |
|---|---|
| `未输入` | 空 |
| `合法·命中` | ✅ |
| `合法·未命中` | ❌（**允许保存**） |
| `非法` | 🔴（**阻止保存**） |

> 「合法但未命中」允许保存 —— 样例值不代表全部数据，不该因一个样例不命中就拒绝合法正则。

### 9.3 规则编辑器

沿用现有 RuleWorkshop 状态，**新增**：

| 状态 | 说明 |
|---|---|
| `参数行编辑中` | 参数表增删行 |
| `间类未选` | 五个勾选框全空 → **警告不阻止**（有些规则可能确实不标间类） |

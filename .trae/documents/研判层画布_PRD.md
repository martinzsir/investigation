## 一、概述

### 1. 需求背景

- **目标用户现状**：侦查研判人员（正兵）目前在同一案件上要分别打开关系图谱（`c/graph`）、地理画像（`c/geo`）、三维交汇（`c/convergence`）和观察档案页，跑完工具后读报告，靠人脑把空间、时间、关系三个维度的结果拼回一个案情。
- **核心痛点**：查到的东西散落在三份报告里，无法长在同一张图上继续往下查；每次调工具都要重新选一遍靶心；结论堆在报告里不知道在证明什么。
- **当前问题汇总**：

| 问题点 | 问题描述 | 当前影响 |
|--------|----------|----------|
| G1 域不对 | 画布种子以 `clue_id` 为域（canvas_seed.py:86），只能从单条线索进 | 长不成案件总图 |
| G3 能力不对 | 14 个研判镜头进画布白名单的为 0（仅 geo 5 个开 `canvas_enabled`），Function 白名单全是资金/通讯类 | 不能在画布上不断增加研判节点 |
| G4 语义不对 | 节点仅 10 类证据溯源语义，无 subject/place/event | 摆不了"人、地、事" |
| 呈现缺口 | 186×50 卡片是 canvas 节点，无法内嵌可视化；节点间跳转丢上下文 | 看细节必须跳页，图丢 |

### 2. 需求目标

- **业务目标**（可验证）：
  1. 在一张案件级画布上完成「摆对象 → 调工具 → 结果长在图上 → 挂假设」的完整研判循环，全程不跳离画布页面。
  2. 精度档（时刻级/日期级）与重名待裁决在图上与窗口中一眼可辨，杜绝"被条数骗"。
- **成功标准**：

| 指标 | 当前状态 | 目标状态 |
|------|----------|----------|
| 节点语义种类 | 10 类（纯溯源） | 14 类（+subject/place/event/analysis_result） |
| 可从画布调度的研判镜头 | 0 个 | 14 个（geo 7 + timeline 3 + relation 3 + vlm 1） |
| 调工具需重复选靶心 | 每次必选 | 选中即带入，0 次重复 |
| 重名自动裁决事件 | 可能错配（42 条交汇 21 条待裁决） | 0 次自裁，100% 显式待裁决标记 |
| 精度档图上可辨 | 不可辨 | 100%（实心/空心 + 实线/虚线双编码） |

### 3. 需求范围

- **包含**：P0 符号口径（canvas-window.ts）；P1 案件级域 + 4 类节点 + 5 类研判边 + `c/canvas` 路由；P2 窗口框架（复合节点按钮、贴附浮窗、5 类分型窗口、卡内迷你符号、放大入口）；P3 生长能力（工具箱、靶心自动带入、`canvas_enabled` 开启、观察回写挂图挂假设）；红线 R1（精度档符号单一来源）、R2（重名不自裁）。
- **不包含**：P4 核查闭环（节点→核查任务→走访回写，下一版本）；旧线索画布迁移（旧快照只读不迁，新画布只认 `case#`）；假设自动裁决；地图在线底图默认开启（仍默认离线 SVG，需用户显式授权）。

## 四、功能说明

### 功能 1：案件级画布与研判节点（P0）

**功能描述**

用户可在 `c/canvas` 页面完成案件级画布的查看与编辑：新增 4 类研判节点（subject/place/event/analysis_result）、既有 hypothesis/note 人工节点，并用研判边（位于/发生于/支撑/反驳/同现）+ 人工边（推断为/证实/查否/补充说明）连线，解决"画布摆不了人地事"的问题。

**用户流程**（含异常路径）

```text
[侧栏 研判中心→研判画布]
  ↓
加载案件画布 GET /cases/{cid}/canvas_case
  ├─ 成功（有节点）→ 渲染 G6 图
  ├─ 成功（空案件）→ 空状态引导卡 → 点「添加节点」
  ├─ 失败（网络）→ 顶部错误条「画布加载失败」+ 重试按钮
  └─ 失败（案件无本体快照）→ 引导「先在接入向导完成数据接入」
  ↓
[添加节点] 工具栏「添加节点」→ 选类型 → 填表单
  ├─ 校验通过 → POST 成功 → 节点出现，1.5s 成功 toast
  ├─ 必填缺失 → 前端先拒，字段红框 + 错误提示（不发请求）
  ├─ 后端 400 → 表单顶部错误横幅（透出后端 reason）
  └─ subject 重名（person_ambiguous=true）→ 节点创建成功但主键留空，
     节点带 ? 标记与虚线边框，弹「待裁决」说明（不阻塞创建）
  ↓
[连线] 工具栏「连线」→ 点源节点 → 点目标节点 → 选关系 → 确认
  ├─ 矩阵合法 → 边创建成功
  ├─ 矩阵非法 → 目标节点置灰不可点，悬停提示原因
  └─ 目标为 source_row/source_file → 直接禁止（承载系统边）
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|----------|----------|----------|--------------|
| loading | 进入页面 | 加载成功/失败 | 全屏骨架 |
| ready | 加载成功 | — | 画布可交互 |
| empty | 加载成功且 0 节点 | 添加首节点 | 居中引导卡 |
| readonly | 旧线索快照（`clue#` 前缀域） | — | 只读横幅，编辑控件隐藏 |

**字段规范**

| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|--------|------|----------|----------|----------|----------|
| subject.person_name | 文本 | 是 | 50 | 非空；建议从主体候选下拉选择 | 「请填写或选择主体名称」 |
| subject.person_pk | 文本 | 否 | 64 | `person_ambiguous=true` 时必须留空 | 「重名待裁决，主键留空」 |
| subject.person_ambiguous | 布尔 | 自动 | — | 后端按 `obj_person_identity` 同名异号判定 | — |
| place.location_id | 文本 | 条件必填 | 64 | 与 lng/lat 二选一必填 | 「请选择地点或填写坐标」 |
| place.lng/lat | 数字 | 条件必填 | — | ∈[-180,180]/[-90,90] | 「坐标超出范围」 |
| place.coord_precision | 枚举 | 否 | — | `门牌级/区划质心/无坐标` | — |
| event.title | 文本 | 是 | 50 | 非空 | 「请填写事件名称」 |
| event.time_start | 日期时间 | 是 | — | 合法时间值（null 不允许，修复历史 Invalid time value 坑） | 「请选择开始时间」 |
| event.time_precision | 枚举 | 是 | — | `minute/date`，默认 `date` | 「请选择时间精度」 |
| analysis_result.lens_id | 文本 | 是 | 64 | 仅接受回写自动生成，人工不填 | 「研判结论由镜头产出自动生成」 |
| 边.edgeNote | 文本 | 否 | 200 | 超限前端截断提示 | 「备注最长 200 字」 |

**文案规范**

| 场景 | 文案内容 |
|------|----------|
| 空状态 | 「这是一张空白的作战地图。放置第一个主体节点，开始研判。」 |
| 加载中 | 「正在载入案件画布…」 |
| 操作成功 | 「节点已添加」「连线已保存」 |
| 操作失败 | 「保存失败：{后端 reason}」 |
| 权限不足 | 「当前角色无画布编辑权限，仅可查看」 |
| 网络异常 | 「网络异常，画布未保存的改动已进入自动保存队列」 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|----------|----------|----------|----------|
| 网络断开 | 请求失败 | 自动保存队列暂存（复用 canvas-autosave），恢复后重放 | 顶栏黄条「离线中，改动已暂存」 |
| 快照冲突 | 并发编辑版本号不一致 | 后端 409，前端提示刷新合并 | 「画布已被他人更新，请刷新后重试」 |
| 数据为空 | 案件无任何主体 | 空状态引导，不请求工具箱 | 引导卡文案 |
| 权限不足 | 无编辑角色 | 控件隐藏（非禁用），API 403 兜底 toast | 「仅可查看」 |

**验收要点**：`python run_tests.py --only canvascase` 全绿；旧 canvas 组（seed/api/edit）回归零失败；`vue-tsc --noEmit` 零错误。

### 功能 2：卡内迷你符号（P0）

**功能描述**

用户可在画布上通过 186×50 复合节点卡内的极简标记（复用 dimDotColor 位置机制），一眼辨识：该节点有无研判内容、什么精度档、是否待裁决，解决"12 条日期级和 4 条时刻级画出来一样"的被条数骗问题。

**用户流程**（含异常路径）

```text
[节点渲染]
  ├─ 有 time_precision → 卡底部画时间色条（长=跨度，位置=时点）
  │    └─ time_start 缺失 → 不画色条（不画占位误导）
  ├─ 有 time_precision → 左下精度点：minute=实心，date=空心
  ├─ person_ambiguous=true → 虚线边框 + 标题后缀 ?（红线 R2）
  └─ 无任何附加数据 → 仅右上维度色点（现状形态，零回归）
```

**状态机**（符号推导纯函数，非交互状态）

| 输入档 | 判定条件 | 输出符号 | 用户可见表现 |
|--------|----------|----------|--------------|
| 时刻级 | `time_precision==='minute'` | 实线粗边标记 + 实心精度点 | 可判时间窗真重叠 |
| 日期级 | `time_precision==='date'` | 虚线细边标记 + 空心精度点 | 仅同地异时 |
| 无时间 | 两字段皆空 | 不渲染时间符号 | 卡片保持紧凑 |
| 待裁决 | `person_ambiguous===true` | 虚线边框 + ? | 覆盖时间符号的边框表达 |

**字段规范**：本功能无用户输入字段。

**文案规范**

| 场景 | 文案内容 |
|------|----------|
| 图例（顶栏「图例」弹层） | 「实心点/实线＝精确到时刻（可判时间窗重叠）；空心点/虚线＝仅日期（同地异时，非同时）；虚线边框＋?＝重名待裁决」 |
| 悬浮提示 | 「该节点为{时刻级/日期级}数据，跨度 {N} 天」 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|----------|----------|----------|----------|
| 脏数据 | precision 非法枚举 | 按无时间档降级渲染，不抛错 | 无符号（静默降级） |
| 跨度缺失 | time_end 为空 | 只画时点标记不画条长 | 悬浮提示不显示跨度 |

**验收要点**：`precisionSymbol()` 纯函数 vitest 断言三档映射 + 反向断言（date 改实线必失败）；符号口径仅存在于 `canvas-window.ts` 单一来源（grep 校验）。

### 功能 3：节点窗口式呈现（P0）

**功能描述**

用户可点击复合节点右上「窗口」按钮，在节点旁弹出贴附浮窗，按节点类型呈现：subject→关系窗口、place→地图窗口、event→时间窗口、analysis_result→证据窗口、hypothesis→假设窗口（fact/source_row→沿用溯源弹层），解决"看细节要跳页、图会丢"的问题。

**用户流程**（含异常路径）

```text
[单击节点] → 选中（高亮 + 工具箱抽屉滑出，功能4入口）
[点节点「窗口」按钮] → 打开浮窗
  ↓
确定窗口类型 windowFor(kind)
  ├─ 有窗口 → 进入 loading（骨架屏，可取消）
  │    ├─ 数据成功 → 渲染分型内容
  │    ├─ 数据为空 → 窗口内空状态文案（如地图窗口：该地点无坐标，仅区划信息）
  │    ├─ 请求失败 → 窗口内错误态 + 重试按钮
  │    └─ 用户连点其他节点 → 取消前请求，仅渲染最新（最新优先）
  ├─ 无窗口（rule/object 等溯源节点）→ 沿用既有 FactDetailPopover
  └─ place 且未授权地图 → 默认离线 SVG 渲染；「启用在线底图」需用户显式点击授权（useMapConsent）
  ↓
[关闭] Esc / 点画布空白 / 再点按钮 → 关闭（钉住除外）
[放大] 窗口右上「放大」→ 跳对应全局视图（P1：带筛选参数）
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|----------|----------|----------|--------------|
| closed | 初始/关闭 | 点窗口按钮 | 无浮窗 |
| loading | 打开请求发出 | 数据到达/失败/取消 | 贴附位置骨架屏 + 取消按钮 |
| open | 数据渲染完成 | 关闭或钉住 | 分型内容 |
| pinned | 用户点「钉住」 | 再点取消钉住 | 窗口角标钉图标；不计入单窗口互斥 |
| error | 请求失败 | 重试成功/关闭 | 错误态 + 重试 |

约束：未钉住窗口同时最多 1 个；钉住窗口最多 3 个；地图实例全页面唯一（复用）。

**字段规范**：本功能无用户输入字段（P1 放大筛选为路由 query，非表单）。

**文案规范**

| 场景 | 文案内容 |
|------|----------|
| 空状态 | 关系窗「暂无一跳关联」；地图窗「该地点暂无可用坐标」；时间窗「暂无时间数据」；证据窗「暂无三维支撑，先运行镜头」；假设窗「尚无支撑/反驳证据挂接」 |
| 加载中 | 骨架屏（无文案）+ 可取消 |
| 操作失败 | 「窗口数据加载失败」+ 重试 |
| 权限不足（地图未授权） | 「在线底图未授权，当前为离线示意模式。启用需外联高德服务」 |
| 网络异常 | 同操作失败 |
| 重名提示（窗口顶横幅） | 「该主体存在同名候选，待人工裁决，本窗口结果未绑定唯一主体」 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|----------|----------|----------|----------|
| 请求竞态 | 快速连点多节点 | AbortController 取消旧请求，最新优先 | 仅显示最后节点窗口 |
| 越界 | 节点靠右/下缘 | 定位翻转到节点左侧/上方；视口滚动跟随 | 窗口始终可见 |
| 地图实例泄漏 | 连开多个地图窗 | 单例复用，关闭仅清图层 | 实例数恒为 1 |
| 在线底图超时 | 授权后 15s 未加载完成 | 错误回调 → 回退离线 SVG | 「在线底图加载超时，已回退离线模式」 |
| 悬浮误触 | （若切换悬浮触发模式） | 默认关闭悬浮模式 | — |

**验收要点**：`CanvasNodeWindow` 组件 spec（开/关/翻转/钉住上限/竞态）；地图唯一性断言（实例计数=1）；离线模式 performance 无高德/Leaflet 请求。

### 功能 4：研判生长（工具箱 + 靶心带入 + 回写）（P0）

**功能描述**

用户选中任一节点后，右侧工具箱自动列出可调度的研判镜头并把选中对象作为靶心自动填入参数（读 pack.json `auto_from`），一键 202 入队；镜头完成后观察产物自动回写为 analysis_result 节点、挂到靶心、有 assumption 归属时再挂「支撑」边到假设节点，解决"每调一次工具都要重新选人、结果回不到图上"的问题。

**用户流程**（含异常路径）

```text
[选中 subject/place/case 节点] → 工具箱滑出：顶部靶心条（已带入，只读）+ 镜头清单
  ↓
[选镜头] → 展开参数确认（auto_from 已填项置灰只读；缺失必填项高亮）
  ├─ 全部就绪 → 「运行」可点 → POST /cases/{cid}/lenses/{skill_id}/run
  │    ├─ 202 → 按钮「已入队」，底部状态条显示任务；用户可继续操作画布
  │    │     └─ 轮询产物完成 → 回写：新 analysis_result 节点挂靶心
  │    │          ├─ 有 assumption → 同时挂「支撑」边到假设节点
  │    │          └─ 完成 toast「镜头产出已上图」+ 新节点脉冲高亮 3s
  │    ├─ 400（参数缺失/停用/草案）→ toast 透出 reason，清单项标灰
  │    ├─ 403（无权限/案件停用）→ 权限提示
  │    └─ 超时（120s 无产物）→ 状态条转「仍运行中，可稍后在观察档案查看」
  ├─ 必填缺失（requires_params 且 auto_from 不覆盖）→ 「运行」禁用，
  │    提示「缺少必填参数：{参数中文名}」
  └─ 镜头 disabled/mode=draft/案件停用 → 清单中置灰不可选，尾注原因
```

**状态机**（镜头任务，前端视图态）

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|----------|----------|----------|--------------|
| idle | 未发起 | 点运行 | 「运行」按钮常态 |
| submitting | 点运行 | 202/4xx | 按钮 loading |
| queued | 收到 202 | 产物回写完成/超时 | 「已入队」徽标 + 状态条任务项 |
| done | 产物回写成功 | — | 新节点上图 + toast |
| failed | 4xx/5xx/超时 | — | toast + 状态条红色标记 |

**字段规范**

| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|--------|------|----------|----------|----------|----------|
| 靶心参数（auto_from 映射） | 文本 | 自动 | 64 | 选中节点 kind 与参数名匹配自动填，置灰只读 | 「请先选中一个{主体/地点}节点」 |
| 其余镜头参数 | 按 params_schema | 按声明 | — | 复用既有 GET 清单 `params_schema` 表单渲染 | 按字段声明透出 |

**文案规范**

| 场景 | 文案内容 |
|------|----------|
| 空状态（未选中节点） | 「选中图上节点即可查看可用研判手段」 |
| 加载中 | 「正在入队…」 |
| 操作成功 | 「镜头已入队」「镜头产出已上图」 |
| 操作失败 | 「镜头调度失败：{reason}」 |
| 权限不足 | 「当前角色不可调度镜头」 |
| 网络异常 | 「网络异常，任务状态稍后自动刷新」 |

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|----------|----------|----------|----------|
| 无观察产出 | 镜头完成但 0 观察 | 不建空节点；状态条标注降级原因（透出 degraded_reason，吸取"无声失败"教训） | 「镜头完成：未产生观察（{原因}）」 |
| 重复调度 | 同靶心同镜头运行中再点 | 运行中镜头项置灰 | 「该镜头已在运行中」 |
| 回写冲突 | 版本前进 | 按 case# 域幂等回写当前版本；旧版本产物自然失效 | 新节点始终挂在当前版本 |
| 假设未确认归属 | 8 个新包装镜头无业务确认 | 仅挂靶心不自动挂假设（开放项③），窗口内可人工补挂 | 节点无假设边不报错 |

**验收要点**：`--only lensrun` 回归全绿；`--only canvascase` 新增回写幂等用例；packs 遍历断言 `canvas_enabled` 集合 = 预期 14 镜头清单；`llm_enabled:false`、shadow 模式等既有红线不变。

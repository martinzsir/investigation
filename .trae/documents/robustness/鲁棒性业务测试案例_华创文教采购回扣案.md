# 鲁棒性业务测试案例：华创文教采购回扣案

> **定位**：全新合成业务案例（非真实案件、非真实人员信息），用于端到端验证孙武侦查官内核的**检测正确性、误报陷阱、降级容错、治理红线（处置/审计/权限）**四层鲁棒性。
> **设计原则**：
> 1. 所有表名、列名、对象/链接、规则挂钩均与当前 ontology default 包（schema_version=2）真实接口一致，无虚构字段；
> 2. 每条数据都标注**设计意图**（真阳性 / 误报陷阱 / 降级探针 / 脏数据），期望值可按 rules.json + functions.json 判据手工复算；
> 3. 案例与既有 golden 三夹具（baseline=张卫国建设案 / false_positive_trap / degraded_single_source）**人员、单位、领域全部不重叠**，不污染既有基线。
> **编制日期**：2026-09-06。对应代码基线：REQ-G-025 修复后（commit 315133f）。

## 一、案件叙事（虚构）

某区教育局副局长**陈学勤**分管教学装备采购。2021 年 9–10 月，"2021 年度智慧教室设备采购项目"由**华创文教设备有限公司**（法定代表人**王润华**）中标，公示日 2021-10-08。举报反映：中标前后陈学勤与王润华私下接触频繁，中标款经王润华之妹**王润芳**经营的"润芳图文工作室"账户走账后，以现金形式回流陈学勤个人账户。

**埋点总览**：

| 层 | 真阳性信号 | 陷阱/探针 |
|---|---|---|
| 资金 | 季末整数现金存入（R1）；公示窗内个人整数资金（R6）；过桥两跳 | 季中整数现金（出窗）、非整数现金（出 round_unit）、房租零头、含尾款待付、公司后缀主体 |
| 通讯 | 公示期主对端频次 8× 常态中位数（R3，非降级） | 单一对端仅 5 次（降级标注且不命中） |
| 轨迹 | 私密场所 ±1 天同框（R4） | 同地点相隔 4 天（出窗）；公开场所同日偶遇（噪声变体 B） |
| 关系 | 法人/关联人命中知识包（R5） | 过期断言、无关法人、姓名子串包含（王润**华清**） |
| 时间 | 公示 ±20 天个人整数资金 2 笔（R6） | 公司主体整数、非整数零头、窗外项目 |
| 举报 | 2 封举报（匿名 + 实名）交叉已在案证据 | 实名举报人不在人员库（归一 LEFT JOIN 不丢材料） |

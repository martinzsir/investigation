### §6 假设自动连线 **缺口**

**操作：** POST geo_accompany/run（origin=张卫国）→ SUCCEEDED；POST relation_org_interest/run（origin=李志强）→ SUCCEEDED

**结果：**
- 画布 nodes 14→16，edges 16→18
- 新增 analysis_result 节点：geo_accompany@person_ecb52c3719fc、relation_org_interest@person_07ed989d84fd
- **新增边全部为「研判得出」系统边，无「推断为」/「支撑」边**
- **无 hypothesis 节点长出**
- 所有 5 个 analysis_result 节点 assumption=None/[]

**根因分析：**
1. `canvas_writeback.py` 的 `build_writeback_doc` 创建 `case#ar:{observation_id}` 节点，但画布上实际是 `case#demoX:analysis_result:{lens}@{pk}` 格式——说明存在**另一条写路径**（canvas_growth.build_result_layer），两条路径并存
2. `build_result_layer` 的假设归属解析失败：assumption_note="镜头 geo_accompany 未在 packs/*/pack.json 注册"——但 geo_accompany 确实在 packs/geo/pack.json 注册（worker 日志 "packs loaded: comm, fund, geo, relation, timeline, vlm, wujian"）
3. `lens_catalog.lens_meta()` 从磁盘读 packs/*/pack.json，与 registry 不同步——registry 有该镜头但 catalog 找不到
4. pack.json 中 geo_accompany 声明了 `assumption: "H6"`，但 `lens_assumption.FUNCTION_RULE` 只覆盖 7 个 function，geo_accompany 的 `geo_spatiotemporal_accompany` 不在其中

**文档假设 vs 实际：**
| 文档 | 实际 |
|---|---|
| H6 假设节点自动长出 | 未长出 |
| 三条结论自动连到假设下，标「推断为」 | 无此边 |
| 灰色细边表示机器推断 | 无边可灰 |
| 人工改「证实」边变实线粗边 | 无法操作（无边） |
| 删边后系统不 reconnect | 无法验证（无边） |

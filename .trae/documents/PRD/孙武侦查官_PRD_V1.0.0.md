# 孙武侦查官 产品需求文档（PRD 落地版）

## 一、概述

**文档信息**

| 版本号 | 日期 | 作者 |
|--------|------|------|
| V1.0.0 | 2026-09-11 | 用户（基于仓库代码反向梳理：frontend / server / core） |

### 1. 需求背景（必写）

- **目标用户现状**：纪检/经侦办案人员在案件研判中面对银行流水、通话记录、轨迹出行、招投标档案、工商登记、举报材料、公开 OSINT 等多源异构数据。数据以 Excel/CSV/Parquet/JSON/SQLite 等分散文件存在，靠人工翻表、Excel 比对和经验记忆找疑点。
- **核心痛点**：人工排查无法跨资金、通讯、行为、关系、时间五个维度做规模化交叉比对；疑点结论依赖个人记忆，既不可溯源到原始数据行，也无法审计每一步处置过程；且研判过程中 AI 若自由下定性结论会带来严重程序风险。
- **当前问题汇总**：

| 问题点 | 问题描述 | 当前影响 |
|--------|----------|----------|
| 多源数据对不齐 | 不同来源表列名、格式、脏值不一，无法直接联表 | 跨源交叉靠人工，漏判多 |
| 线索无血缘 | 疑点结论说不清由哪条假设、哪些原始行推出 | 无法复核、无法出庭举证 |
| 处置无留痕 | 线索状态变更缺少受控状态机和操作审计 | 程序瑕疵、责任不清 |
| AI 越权风险 | 大模型可能直接定性、直连公网泄露案情 | 办案安全与保密红线 |

### 2. 需求目标（必写）

- **业务目标**（可验证）：
  1. 一个新案件从文件上传到产出首批带血缘的候选线索，全程由版本化任务自动完成，办案人员只需做列映射确认和人工处置。
  2. 每条线索均可一键追溯到「规则判据 + 假设链 + 原始数据行」，每次状态变更均落审计链；系统在任何界面不输出定性结论、不提供自动立案。
- **成功标准**：

| 指标 | 目标状态 |
|------|----------|
| 数据接入格式覆盖 | CSV/Excel/Parquet/JSON/SQLite 五类可直接上传接入 |
| 线索可溯源率 | 100% 线索携带 source_rows 与规则版本（无血缘不产出） |
| 写操作受控率 | 100% 写操作经 Action 校验（角色/必填参数/状态机/副作用） |
| 版本可回滚 | 每次构建产出独立版本文件，仅成功才切指针，旧版本读者不中断 |

### 3. 需求范围（必写）

- **包含**：账号会话与密级权限；案件门户（建案/结案/封存）；五格式数据接入向导与列映射；语义层版本化构建（obj_*/lnk_*）；任务中心；确定性线索推演（R1~R6 规则、五技能链路）；线索列表/详情；处置看板（五状态机）；实体人审裁决；审计链；数据画像/接入建议；数据治理五件套（数据元/ETL/映射校验/质量检查/隔离区）；研判模型四件套（模型设计器/规则工坊/知识包/权限遮蔽）；庙算工作台；知识图谱；跨案件查询；案件包导出导入；代码逃生舱；系统设置；LLM 三档治理（off/local/cloud）与 MCP 通道。
- **不包含**：移动端/小程序；多租户运营管理后台（代码含 tenant 字段，本版仅做数据隔离不做租户运营）；系统自动定性或自动置「已立案」；无脱敏代理直连公网 LLM；支付/地图/消息推送等业务无关第三方服务；产品计费功能。

## 四、功能说明

### 功能 1：账号登录与会话（P0）

**功能描述**：办案人员在登录页凭工号和密码换取会话 Token，系统加载其角色、密级与管理员标志，用于全站鉴权与字段遮蔽。

**用户流程**（正常 + 异常）

```text
[登录页]
  ↓ 输入工号/密码（双因子验证码为预留输入位）
[提交 POST /auth/login]
  ├─ 成功(200) → 存 token（内存+sessionStorage）→ GET /auth/me → 跳 redirect 或治理仪表盘
  ├─ 凭据错误 → 登录页内联错误提示，保留工号、清空密码
  ├─ 账号停用/不存在 → 同上，不区分账号与密码错误（防枚举）
  └─ 网络异常/超时 → 顶部错误条，可重试，不清空已填内容
[已登录后访问受保护页]
  ├─ 会话有效 → 放行
  ├─ 无 token → 跳登录页并携带 redirect 参数
  └─ token 失效(401) → 清本地会话回登录页
[登出] → 调 /auth/logout（失败也清本地）→ 登录页
```

**状态机**

| 状态名称 | 进入条件 | 退出条件 | 用户可见表现 |
|---|---|---|---|
| 未登录 | 无 token / 登出 / 401 | 登录成功 | 登录页 |
| 已登录 | /auth/login 返回 token 且 /auth/me 成功 | 登出、token 失效、过期 | 应用外壳全部业务页 |
| 登录失败态 | 接口返回失败 | 再次编辑输入或重试 | 字段下红字+轻提示，停留登录页 |

**字段规范**

| 字段名 | 类型 | 是否必填 | 长度限制 | 校验规则 | 错误提示 |
|---|---|---|---|---|---|
| operator（工号） | 文本 | 是 | 1–64（建议默认值） | 非空、去首尾空格 | 请输入工号 |
| password | 密码 | 是 | 建议默认值 1–128 | 非空 | 请输入密码 |
| otp（双因子验证码） | 文本 | 否（建议默认值：前端已预留输入位，后端当前不强制校验） | 6–8 位数字 | 数字 | 验证码格式不正确 |

**文案规范**

| 场景 | 文案内容 |
|---|---|
| 空状态 | 输入工号和密码登录（placeholder：工号 / 密码 / 双因子验证码） |
| 加载中 | 登录中…（按钮 loading，防重复提交） |
| 操作成功 | 不弹提示，直接进入目标页 |
| 操作失败 | 工号或密码错误（账号与密码错误统一文案） |
| 权限不足 | 当前账号无权访问该内容 |
| 网络异常 | 网络异常，请稍后重试 |

登录页侧栏固定安全提示："严禁截屏外传"、"操作全程留痕可追溯"。

**异常情况处理**

| 异常场景 | 触发条件 | 处理方式 | 用户反馈 |
|---|---|---|---|
| 网络断开 | 请求失败 | 不跳转、保留输入 | 网络异常，请稍后重试 |
| 会话过期 | 业务接口 401 | 清 token+me，带 redirect 回登录 | 登录已过期，请重新登录 |
| 重复提交 | 登录中再次点击 | 按钮 loading 禁用 | — |
| 越权访问管理页 | 非管理员进入系统设置 | 路由/接口双闸门 | 无权限提示或入口不可见 |

### 功能 2：案件门户与案件生命周期（P0）

**功能描述**：用户在门户创建案件、按状态筛选检索并进入工作台；案件随首版构建自动"立案"进入侦查中，并支持结案与封存压实。

**用户流程**

```text
[案件门户]
  ├─ 新建案件（弹窗）
  │    ├─ 编号/名称合法 → POST 创建（状态=待建案，pack=default 快照）→ 进入新案件
  │    ├─ 编号非法/重名/超长 → 字段下红字，禁止提交
  │    └─ 创建失败 → 弹窗错误提示，保留已填内容
  ├─ 状态 Tab（全部/待建案/侦查中/已结案/已封存）+ 关键词搜索 → 卡片过滤
  ├─ 点击卡片 → 进入案件（后端打开当前生效版本）
  │    └─ 版本文件缺失/案件不存在 → 返回门户并提示
  ├─ 结案 → 二次确认弹窗 → 状态=已结案
  └─ 封存 → 触发 ARCHIVE 任务 → 仅保留最终版本，其余版本文件物理回收
```

**状态机（案件）**

| 状态 | 进入条件 | 退出条件 | 用户可见 |
|---|---|---|---|
| 待建案 | 建案成功 | 首次 BUILD 成功（worker 自动迁移） | 灰色标签 |
| 侦查中 | 首版语义构建成功 | 人工结案 | 主色标签 |
| 已结案 | 人工结案确认 | 封存 | 标签 |
| 已封存 | ARCHIVE 任务成功（仅已结案可封存压实） | 不提供前台逆向迁移（终态） | 标签，版本列表只余最终版 |

**字段规范（新建案件）**

| 字段名 | 类型 | 必填 | 长度 | 校验规则 | 错误提示 |
|---|---|---|---|---|---|
| 案件编号 | 文本 | 是 | 1–64 | 字母/数字/下划线/中划线；租户内唯一 | 仅支持字母、数字、下划线、中划线，1–64 字符 |
| 案件名称 | 文本 | 是 | 1–128 | 非空 | 请输入 1–128 字案件名称 |
| 案件包 | 隐式 | — | — | 固定 default；建案后首次 BUILD 锁定快照 | — |

**文案规范**

| 场景 | 文案 |
|---|---|
| 空状态 | 还没有案件 / 新建第一个案件，开始确定性侦查推演 |
| 无结果 | 无匹配案件 / 调整状态筛选或搜索关键词 |
| 操作成功 | 案件已创建 / 案件已结案 / 已封存并压实 N 个历史版本 |
| 操作失败 | 创建失败：{后端消息} |
| 二次确认 | 结案后该案件将进入只读归档态，确认结案？ |

**异常情况处理**

| 异常场景 | 触发 | 处理 | 反馈 |
|---|---|---|---|
| 编号重复 | 唯一约束冲突 | 不创建 | 案件编号已存在 |
| 封存时非已结案 | worker 校验 | 任务 FAILED | 仅已结案案件可封存压实 |
| 进入案件版本不存在 | 当前版本文件丢失 | 回门户 | 案件版本缺失，请重建或联系管理员 |
| 卡片摘要加载失败 | summary 接口失败 | 卡片仍可进案，待办显示"—" | 不阻断进入 |

### 功能 3：五格式数据接入向导（P0）

**功能描述**：单文件四步向导（上传→列分析与映射→导入确认→完成），支持 CSV/Excel/Parquet/JSON/SQLite，导入立即返回任务，自动链式触发版本化构建。

**用户流程**

```text
[步骤1 上传文件]
  ├─ 选文件（扩展名白名单）→ 上传 → 后端指纹+列画像
  │    ├─ 重复指纹 → 409，提示"文件已存在"，不重复入队
  │    ├─ 不支持格式 → 拒绝选择/红色提示
  │    └─ SQLite 多表 → 步骤2出现库内表选择（默认首表）
  ├─ JSON 嵌套未展平/分隔符不匹配 → warning 但继续进入向导
[步骤2 列分析与映射]
  ├─ 自动建议映射（低置信琥珀高亮），用户可改选源列
  ├─ 必选列未映射 → 琥珀警告（不阻断，允许进下一步）
  └─ 清洗链按声明展示（本版向导内只读采用）
[步骤3 确认导入]
  ├─ 展示将映射列、缺失必选列、目标表 → 提交 IMPORT
  │    └─ 提交即返回 task（不轮询等待）→ 自动跳任务中心看 SSE
  └─ IMPORT 成功后 worker 自动链式 BUILD
[步骤4 完成] → 展示导入行数/新版本号，入口跳线索列表或继续上传
```

**状态机（数据源行）**：imported（成功落冷层并登记 case_sources）；失败时不产生冷层文件（临时目录写 parquet，原子 rename，失败零残留）。

**字段规范**

| 字段 | 类型 | 必填 | 规则 | 错误提示 |
|---|---|---|---|---|
| 上传文件 | 文件 | 是 | 扩展名 ∈csv/tsv/txt/xlsx/xls/parquet/pq/json/ndjson/jsonl/db/sqlite/sqlite3 | 不支持的文件格式 |
| 目标表 | 单选 | 是 | 声明表之一 | 请选择目标表 |
| SQLite 库内表 | 单选 | 多表时必填 | 上传文件内实有表 | 请选择要导入的表 |
| 列映射 | 声明列→源列下拉 | 必选列业务必填 | 源列必须真实存在 | 必选列「X」尚未映射 |

**文案规范**

| 场景 | 文案 |
|---|---|
| 上传区 | 选择或拖入案件数据文件（支持 CSV / Excel / Parquet / JSON / SQLite） |
| 加载中 | 正在分析文件列… / 导入任务已提交 |
| 成功 | 导入任务已提交，可在任务中心查看进度 |
| 重复 | 文件已存在，已跳过 |
| 缺必选列 | 缺少必选列：{列名}，该列将降级为空值（建议默认值：警告但允许继续，与代码非阻断语义一致） |

**异常情况处理**

| 异常 | 处理 | 反馈 |
|---|---|---|
| 网络断开/大文件中断 | 上传失败不留半成品 | 上传失败，请重试 |
| 解析失败（坏文件） | 后端任务 FAILED，错误码落任务 | 任务中心显示原因（如"无法解析的 JSON"） |
| 脏值类型不符 | 编译期 TRY_CAST，脏值降级 NULL 并记诊断 | 构建完成提示 N 列降级，可去质量检查查看 |
| 重复导入 | 幂等键拦截 | 文件已存在，未重复导入 |

### 功能 4：版本化语义构建与任务中心（P0）

**功能描述**：IMPORT/RESCAN 等触发 BUILD 任务：复制当前版本→挂载冷层→编译 obj_*/lnk_* 语义层→跑线索检测→仅成功才切版本指针；任务中心用 SSE 实时呈现。

**任务状态机**

| 状态 | 进入 | 退出 | 表现 |
|---|---|---|---|
| PENDING | 入队（幂等：case+type+idem_key 冲突返旧任务） | 被 worker 认领 / 被取消 | 排队中 |
| RUNNING | worker 认领 | 成功/失败 | 进度条+阶段标签+详情（SSE 推送） |
| SUCCEEDED | 处理器成功（BUILD 后切版本并产出 clues_vN.json） | 终态 | 绿色，可看产物 |
| FAILED | 处理器抛业务错误（带 code/message） | 终态（可重新入队） | 红色，显示错误码与信息 |
| CANCELLED | 仅 PENDING 可人工取消 | 终态 | 灰色 |

**版本状态机**：active（当前生效）→ 新版本生效后旧版 pending_reclaim → 封存压实时 reclaimed（文件物理删除）。构建失败时 vN 残留但指针不动，下次构建先删残留再重建；旧读者始终持有旧文件句柄不受影响。

**字段/交互**：任务类型固定枚举 IMPORT/BUILD/DISPOSE/REVIEW/RESCAN/EXPORT/IMPORT_PACKAGE/QUALITY_CHECK/DIAGNOSE/DE_RECOMMEND/DE_RECO_DECIDE/ARCHIVE/PING；进度 0–100；阶段标签中文（准备构建/挂载冷层数据源/装载本体声明/语义层编译完成/线索检测完成/构建完成）。

**文案规范**：加载中"构建中 v{n}…"；成功"v{n} 已生效，产物 {n} 条线索"；失败"构建失败：{message}，版本未前进可重试"；取消"仅排队中任务可取消"。

**异常处理**：冷层挂载失败（COLD_MOUNT_FAILED）、线索检测失败（DETECTION_FAILED）均整体视为 BUILD 失败，指针不前进；附属诊断产物落盘失败只记 ops 事件、不回滚版本；SSE 断线时任务中心改为轮询兜底（建议默认值），重连后继续实时进度。

### 功能 5：线索列表与线索详情（P0）

**功能描述**：列表页按状态/规则/维度等筛选全量线索；详情页展示计分依据、证据、完整血缘（假设链 H+源行溯源+间类归属）与处置留痕。系统只呈现候选线索与证据，不输出定性结论。

**用户流程**：列表筛选/排序→点进详情→查看证据明细与溯源行（可跳源表行级溯源）→在详情页发起处置（见功能 6）；无匹配筛选结果显示空态；线索不存在（旧链接）返回列表。

**字段规范（展示态，非录入）**：clue_id、标题、产出技能（miaosuan/zhi_ji_zhi_bi/xu_shi/qi_zheng/yong_jian）、规则 id(R1~R6)与规则版本、假设链、间类（因/生/反/死/内间）、五间交叉等级、分值/计分因子、状态、note。

**文案规范**：空状态"无符合条件的线索，试试调整筛选条件"；加载骨架屏；溯源标题"该线索由假设 {Hn} 与 {N} 条原始记录推出"；红线提示位固定文案"系统仅提供候选线索，不做定性结论"。

**异常处理**：版本切换后旧线索 id 不存在→404 返回列表；SSE/接口降级时展示静态快照数据并标注数据时间；越权看敏感字段→按遮蔽策略显示（如 310****1234），不返回明文。

### 功能 6：线索处置看板——五状态受控迁移（P0）

**功能描述**：用户在看板或详情页对线索执行 7 个声明动作中的线索处置动作；所有迁移经唯一写通道 ActionExecutor 校验角色、必填参数、状态机与副作用，每次迁移落审计链。

**状态机（合法迁移，与 actions.json/states 声明一致）**

| 当前状态 | 可迁目标 | 动作 | 必填参数 |
|---|---|---|---|
| 待查 | 查证中 / 已排除 | verify / exclude（注：待查不能直接固证，须先查证） | exclude 需 reason |
| 查证中 | 待查 / 已排除 / 已固证 | reset / exclude / confirm | exclude 需 reason |
| 已排除 | 待查（新证据重开） | reset | — |
| 已固证 | 已排除 / 已立案 | exclude / file | file 需 legal_basis + human 角色 |
| 已立案 | 终态，无出口 | — | — |

**用户流程**

```text
[看板/详情点动作]
  ├─ verify 开始查证 → 状态=查证中（任意登录角色可执行）
  ├─ exclude → 必填"排除理由"弹窗 → 提交
  ├─ confirm 固证（仅"查证中"可点；待查态按钮置灰）
  ├─ file 立案 → 必填"法定依据（案号/审批文号）"
  │    ├─ 当前非已固证 → 后端拒绝（须先固证）
  │    ├─ 操作人非 human 角色（含 agent: 身份）→ 拒绝
  │    └─ 通过 → 创建 obj_decision 决策对象，状态=已立案（终态）
  └─ reset 退回待查（重开）
```

**字段规范**

| 字段 | 类型 | 必填 | 校验 | 错误提示 |
|---|---|---|---|---|---|
| reason（排除理由） | 文本 | 是 | 非空白 | 排除必须填写理由 |
| legal_basis（法定依据） | 文本 | 是 | 非空白，建议 2–128 字 | 请填写案号或审批文号 |
| operator | 隐式 | — | 一律取会话主体，请求体 operator 被忽略 | 操作人与登录身份不一致 |

**文案规范**：空列"暂无{状态名}线索"；成功"已标记为查证中/已排除/已固证/已立案"；失败"操作被拒绝：{message}"；权限不足时按钮不可见而非可点报错；立案按钮旁始终提示"立案为受控终态，需法定依据且仅人工可执行"。

**异常处理**：非法迁移（如待查直接固证）→后端 4xx，前端按钮按状态机禁用，双保险；写时降级（只读版本/库锁）→409 DEGRADED_WRITE_REJECTED，提示稍后重试；并发改同一线索→以审计链最后状态为准刷新看板（看板数据为快照，处置后重新拉取）。

### 功能 7：实体人审裁决（P0）

**功能描述**：同名实体解析产出 needs_review 候选（强证据冲突，如同名不同电话/证件），系统只列候选不静默合并；由人工在实体裁决页确认合并或驳回，落 state.review_decision 并创建决策对象（不产版本）。

**用户流程**：进入裁决页→查看主实体与候选实体的证据对比（来源行/电话/证件）→确认合并（review_merge 需 candidate_id）或驳回（review_reject 需 candidate_id+reason）→候选出队、审计留痕；LLM 判读参考卡片仅展示参考意见，不含裁决按钮。

**状态机**：候选 待裁决 → 已合并（merge_entity，写别名/簇）/ 已驳回（dismiss_review，不再入队）；两动作均 requires_role=human。

**字段规范**：candidate_id 文本必填（来自列表，不由手输）；驳回理由 必填非空。错误文案："请选择待裁决候选"、"驳回必须填写理由"。

**文案/异常**：空状态"暂无待裁决实体"；成功"已确认合并 / 已驳回该候选"；候选已被他人裁决→刷新列表提示"该候选已处理"；agent 身份调用→拒绝并提示仅人工可裁决。

### 功能 8：权限与字段遮蔽（P0）

**功能描述**：每个会话携带角色密级（见习 0/正兵 1/偏将 2/主办 3/human 4，system 旁路仅本机），对象级/链接级策略未声明一律 fail-closed；属性级敏感列按角色遮蔽（如手机号 310****1234）。权限在网关/Function/Action/MCP/导出五个出口统一生效。

**用户流程**：任意列表/详情/接口请求→后端依策略决定可见对象与字段→前端按遮蔽后值渲染；越权对象整行不可见；权限与遮蔽页提供按角色预览。无"申请权限"流程（建议默认值：本版不做自助申请，找管理员调整）。

**规则（无输入字段，列规则）**：角色名固定枚举；operator 与 AccessContext 不一致的写操作拒绝；agent: 前缀身份仅可用只读工具与 review.submit_proposal；local 会话只允许 local 档 LLM，web 会话才允许 cloud 档，会话面与策略面取交集 fail-closed。

**文案规范**：遮蔽位保留原文长度星号；整对象无权时列表不出现该对象（而非显示"无权"行，避免存在性泄露，建议默认值）；导出越权字段→导出清单中显示"已遮蔽 N 列"。

**异常处理**：策略缺失→硬拒绝（不默认放行）并落诊断；MCP 缺身份环境变量→拒绝建立会话；cloud 档未经脱敏代理→LLM 调用直接拒绝。

### 功能 9：审计链（P0）

**功能描述**：线索处置、实体裁决、构建生命周期、提案等动作均追加不可变审计事件（操作人、前后值、溯源行 id、规则/本体版本）；审计链页支持筛选与完整性校验。

**用户流程**：进入审计链→按操作人/动作类型/案件筛选→展开单条看 before/after 与溯源→顶部健康灯指示链校验结果；案件门户卡片同步展示链健康点。

**状态/规则**：事件只追加不可改；空链追加受红线约束；链完整性校验失败→仪表盘/门户亮红灯但不阻断读操作。

**文案规范**：空态"暂无审计记录"；校验失败红色横幅"审计链校验未通过，请联系管理员"；单条标题"{operator} 执行了 {action}"。

**异常处理**：审计追加失败的旁路动作（如构建后生命周期审计失败）只记 ops_events，不回滚主业务；篡改历史库文件→校验报不一致并告警。

### 功能 10：治理仪表盘（P1）

**用户流程**：进案默认页→查看五间交叉雷达、高优先级线索（按计分排序）、案件健康与版本/数据新鲜度指标→点击线索卡进详情。**状态**：指标随版本刷新（构建后数据版本号变化，前端重新拉取）。**文案**：加载失败各卡片独立降级显示"数据暂不可用"，不整页白屏。**异常**：SSE 未连接时显示上次快照并标注时间。

### 功能 11：数据画像（P1）

**用户流程**：选表→看 L0 表概况/L1 列画像（非空率、样本、推断类型）/L3 关注命中与指标/L4 五间分布/L5 质量分（100+Σ扣分）→对启发式扣分可人工推翻→书写变体候选可跳转接入向导。**字段**：质量扣分为整数分，每条扣分带原因码与列名。**异常**：表无数据→展示空画像骨架并提示先接入数据；画像计算超时→分节懒加载，未算章节显示占位不阻塞。

### 功能 12：接入建议（P1）

**用户流程**：上传并分析后，系统基于暂存件采样生成列映射/数据元推荐→用户逐条采纳或驳回（DE_RECOMMEND/DE_RECO_DECIDE 任务，只记 state+审计，不改 bindings）→采纳结果作为向导默认映射。**状态机**：推荐 待裁决→已采纳/已驳回。**异常**：采样件不足→推荐为空时向导退回手动映射并提示"样本不足，未生成建议"。

### 功能 13：数据治理五件套（P1）

- **数据元**：浏览数据元素字典（类型/单位/敏感级）；只读为主。
- **ETL 管道**：查看表的 clean（py op）/transform（sql op）链；op 名与参数白名单由注册表校验，自由文本参数硬失败。
- **映射校验**：源列↔声明列全量核对报告，缺列/未用列/低置信分别列示。
- **质量检查**：手动发起 QUALITY_CHECK 任务（四扫描汇总落 state），完成后看汇总分与明细；可重跑。
- **隔离区**：浏览被 reject_if 等规则拒绝的脏行及隔离原因，支持查看原始值（按权限遮蔽）。
- **共同异常**：诊断/检查任务失败不影响当前版本；导出隔离数据需权限并留审计。

### 功能 14：研判模型配置四件套（P1）

- **模型设计器**：浏览/编辑对象（obj_*）与链接（lnk_*）声明（pk、kind=entity/event、name_property、属性值类型）；保存后需要新 BUILD 生效，非法声明由 loader 硬失败并逐行报错。
- **规则工坊**：浏览 R1~R6 规则的 rule_text（自然语言判据，只读展示给人/LLM）与 params（机器挂钩）；改阈值/启停规则→触发 RESCAN 任务复用 BUILD 编排产新版本；无匹配函数返回 no_matching_function，不生成自由 SQL。
- **知识包**：维护 case_knowledge（subject_aliases 主体别名等），案例沉淀脱敏门以此拦截真名入库。
- **权限与遮蔽**：见功能 8 的配置视角。
- **异常**：loader 校验失败（交叉引用不存在/版本不符/参数与占位符不一致）→整体硬失败，页面显示逐项错误清单且不写半成品；规则参数非法（如整数阈值传非数字）→前端禁用保存。

### 功能 15：庙算工作台（P1）

**用户流程**：查看/维护假设（H1~Hn，每条挂 data_sources）→查看间类（因间/生间/反间/死间/内间）→假设驱动后续技能产出线索的 assumption_chain。**状态**：假设变更随审计留痕（建议默认值：假设为研判配置，不直接产出线索）。**异常**：未完成"知己"（miao.ji 为空）时调用后续阶段技能前置校验失败，工作台提示先补知己。

### 功能 16：知识图谱（P1）

**用户流程**：打开图谱→节点（人/组织/账户/项目等）与边（转账/通话/同框/持股/涉案等）力导布局→点节点看属性与关联线索→进入线索详情。**异常**：图库数据由语义层经 CSV 中转构建（Windows）/ATTACH（Linux）；构建中→占位提示；无边数据→空图态"当前版本暂无可展示的关系"。

### 功能 17：跨案件查询 / 案件包 / 代码逃生舱（P1）

- **跨案件查询**：跨 case_id 关键词/规则/outcome 检索线索与已沉淀案例片段；空态"未检索到跨案件线索"。
- **案件包**：EXPORT 任务导出 zip（版本压实+审计链冻结+SHA-256 校验）；IMPORT_PACKAGE 校验后 init_pack 并登记；导入损坏→校验失败拒收且不覆盖现有包。导出须 operator/role/purpose/destination 留审计。
- **代码逃生舱**：声明体系无法表达的只读取数经白名单 SQL（SELECT/WITH）+模板参数（数值正则、string 仅 enum）执行，结果只给聚合不给原始明细；写 SQL 一律拒绝。

### 功能 18：系统设置（P1）

仅 is_admin（或 system 角色）可见：会话管理、平台参数（settings_kv，修改留 reason）、运行健康与降级总览。非管理员入口隐藏且接口 403。保存设置必须填写变更原因。异常：参数值非法→拒绝并提示合法取值。

### 功能 19：LLM 判读与提案通道（P1）

**用户流程**：在实体裁决等页面查看 LLM 判读参考（仅建议）；具名 agent 助手（agent: 前缀）可经 MCP 使用只读工具（rule_list/clue_list 等）并通过唯一写通道 review.submit_proposal 提交提案（pp- 前缀），提案进人审队列，不直接生效、不触 ActionExecutor/DisposalBoard。

**LLM 网络治理状态机（部署面三档）**：

| 档位 | 允许端点 | 数据策略 | 默认 |
|---|---|---|---|
| off | 无网络调用 | — | 默认（llm_enabled=false，shadow 纯离线） |
| local | 仅 loopback 与 RFC1918 内网段（DNS 解析后校验 IP 防绕过） | relaxed 脱敏（人名明文，轨迹点/通话正文/证件卡号仍脱敏） | 显式开启 |
| cloud | 公网 API | strict 全套 tokenize/drop/rehydrate，经脱敏代理 | 仅 web 会话+案件包显式声明 |

**异常**：名义 local 实指向公网→拒绝调用并告警；无匹配函数→no_matching_function；会话面与策略面交集为空→fail-closed 拒绝。

## 部署形态（业务与技术兼顾）

- **内网单机**：本机/WSL 运行 uvicorn(:8000)+worker，DuckDB/SQLite/Parquet 本地文件，浏览器访问 127.0.0.1，LLM 默认 off/local（Ollama loopback）。
- **公网服务器**：服务前置 TLS 反向代理（建议默认值：由 nginx/网关终止 HTTPS）；CORS 默认关闭，经 `SUNZI_CORS_ORIGINS` 白名单放行；会话仍为 Bearer + 服务端 PBKDF2 口令；文件存储挂服务器持久盘阵；cloud 档 LLM 必须走严格脱敏代理；MCP 不经公网暴露（建议默认值：MCP 仅本机 stdio，不随 Web 公网发布）；导出/逃生舱等敏感出口保持五出口权限校验与审计。

## 1. 声明文件（ontology/default，换案件只改 JSON 不改代码）

| 文件 | 需求 | 内容 |
|---|---|---|
| `jians.json`（新增） | R5/R9 | 五间全名（因间/内间/反间/死间/生间）、default_clearance、权重、source_object_types；cross_levels（观察/线索/可立案依据候选，1/2/3 独立源映射仍硬编码校验）；source_independence |
| `states.json`（新增） | R6/R10 | 状态机声明：SLA（待查 3 / 查证中 5 / 已固证 7，终态省略）、tone、terminal/outcome；confirm 仅 `查证中`、verify 标题「开始查证」、reset「退回待查」、旁路态 tone=muted 置末、已立案 human 专属 |
| `scoring.json`（新增） | R7/R12/R13 | 计分权重外置；产线携带 score_basis（每维 raw/weight/contrib）、score_formula、score_source |
| `derived_properties.json`（新增） | R8 | 派生属性声明：function/inputs/cache_policy |
| `actions.json`（修改） | R3 | 写动作声明补全 |
| `functions.json`（修改） | R3/R4/R9 | FunctionSpec.requires 声明、表名参数化；新增 tipoff_cross_reference、call_pair_coverage |

关键决策（已拍板）：
- D1 confirm `only_from:["查证中"]`；D4 verify/reset 标题如上；D5 旁路态 muted 置末；D6 间类全名精确匹配
- ROLE_CLEARANCE：见习 0 / 正兵 1 / 偏将 3 / 主办 3 / human 3 / system 99；未知角色 = 1（fail-closed）；未声明间类 = 99
- 兵法五间（jians.json：因/内/反/死/生，线索 jian_types，密级过滤）与侦查五维（dimensions.json：资金/通讯/行为/关系/时间，detail.dimension，雷达/房间徽章）严格双轨不混

## 7. 红线保持

- 无业务 SQL 直写（统一 Function/Action 编排）；检测器/图库/MCP 不直读 Parquet，只消费 obj_*/lnk_*
- 写操作唯一入口 ActionExecutor；Function 只读
- 1/2/3 独立源交叉映射仍硬编码（名称可配、映射不可配，loader 硬校验）
- 「已立案」requires_role=human 终态，正兵及以下不可达
- 对象/链接策略未声明 fail-closed；敏感列遮蔽不变

# 孙武侦查官 SaaS · 组件规范 v1.0

**适用**：React 19 + Tailwind v4 + shadcn/ui(Base UI)
**原则**：所有颜色、间距、字号**只走 token**，禁止在组件里写死色值。

## 一、色彩系统

### 1.1 基础色（严格对应原型）

```css
:root {
  /* 背景层级 —— 四层，越靠上越亮 */
  --bg-base:      #0A0E1A;  /* 页面底 */
  --bg-elevated:  #121826;  /* 卡片 */
  --bg-hover:     #1A2337;  /* 悬停 */
  --bg-active:    #223050;  /* 选中/按下 */

  /* 边框 */
  --border-subtle:  #1E2739;
  --border-default: #2A3purpose → #2A3550;
  --border-strong:  #3A4A6B;

  /* 强调 */
  --accent:      #00D4FF;
  --accent-dim:  rgba(0, 212, 255, 0.15);
  --accent-glow: rgba(0, 212, 255, 0.35);

  /* 文字四级 */
  --text-primary:   #E8EDF5;
  --text-secondary: #8B9BB4;
  --text-muted:     #5A6B85;
  --text-disabled:  #3D4A5C;
}
```

### 1.2 语义色（每个语义三档：底 / 边 / 字）

这是**最容易做错的地方**——很多深色主题只定义一个色值，导致徽章、边框、文字全用同一个颜色，对比度失控。必须三档分开：

| 语义 | 底色 bg | 边框 border | 文字/图标 text | 用途 |
|---|---|---|---|---|
| **ok** 正常 | `rgba(76,175,80,.15)` | `#4CAF50` | `#81C784` | 健康、通过 |
| **warn** 警示 | `rgba(255,167,38,.15)` | `#FFA726` | `#FFB74D` | warning 级诊断、超期 |
| **error** 错误 | `rgba(255,82,82,.15)` | `#FF5252` | `#FF8A80` | 失败、冲突、空链 |
| **info** 信息 | `rgba(0,212,255,.12)` | `#00D4FF` | `#4DD8FF` | 常规提示、进行中 |
| **filed** 已立案 | `rgba(255,179,0,.18)` | `#FFB300` | `#FFD54F` | 受控终态专用 |

### 1.3 五间色（本项目特有）

五间命中横条、枚举热力图都要用。**这是项目特有的语义维度，通用 UI 库没有，必须自建。**

| 间类 | 色值 | 含义 |
|---|---|---|
| 资金 | `#FFB300` 金橙 | 资金流 |
| 通讯 | `#00D4FF` 青蓝 | 通话、联系 |
| 行为 | `#B388FF` 紫 | 轨迹、位置 |
| 关系 | `#4CAF50` 绿 | 社会关系 |
| 时间 | `#FF7043` 橙红 | 时序 |

> **注意**：`filed`（已立案）用金橙，与「资金」间类同色系，容易混淆。区分办法是**已立案必带锁图标 + 法定依据文字**，间类色只出现在横条与热力图里，不在状态标签里出现。

## 二、字体与排版

```css
--font-sans: "Noto Sans SC", "Source Han Sans SC", system-ui, sans-serif;
--font-mono: "JetBrains Mono", "Fira Code", monospace;
```

| 层级 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| display | 24px | 1.3 | 600 | 页面大标题 |
| h1 | 20px | 1.3 | 600 | 区块标题 |
| h2 | 16px | 1.4 | 600 | 卡片标题 |
| h3 | 14px | 1.4 | 500 | 小标题 |
| body | 13px | 1.5 | 400 | 正文（**默认**） |
| sm | 12px | 1.5 | 400 | 表格、辅助 |
| xs | 11px | 1.4 | 400 | 标签、时间戳 |

**默认 13px 而非 14px** —— 原型是密集布局，13px 是信息密度与可读性的平衡点。

数字、ID、哈希值、代码用 `--font-mono`，便于对齐辨识。

## 三、间距与密度

```css
--space-1: 4px;   --space-2: 8px;   --space-3: 12px;
--space-4: 16px;  --space-5: 20px;  --space-6: 24px;  --space-8: 32px;
```

**密度两套，可切换**（原型按 1920×1080 画的，1366×768 必须能切）：

| Token | 紧凑 compact | 舒适 cozy |
|---|---|---|
| 表格行高 | 28px | 40px |
| 卡片内边距 | 12px | 16px |
| 区块间距 | 12px | 20px |
| 正文字号 | 12px | 13px |

切换方式：`<html data-density="compact">`，Tailwind 用 `data-[density=compact]:` 变体消费。

## 四、核心组件规范

### 4.1 卡片 Card

```
┌─────────────────────────────┐
│ 标题区 h2 16px    [操作]     │  ← 高 40px，下边框 1px
├─────────────────────────────┤
│                             │
│ 内容区 padding 12/16px      │
│                             │
└─────────────────────────────┘
```

| 项 | 值 |
|---|---|
| 背景 | `--bg-elevated` |
| 边框 | 1px `--border-subtle` |
| 圆角 | 8px |
| 阴影 | `0 1px 3px rgba(0,0,0,.4)` |
| hover | 边框转 `--border-default` |

**强调卡片**（健康度横幅）额外用 2px 左边框，颜色取当前状态语义色。

### 4.2 表格 Table

原型的核心载体，17 页里有 9 页主结构是表格。

| 元素 | 规范 |
|---|---|
| 表头 | 背景 `--bg-base`，12px，字重 500，`--text-secondary`，**吸顶** |
| 数据行 | 背景 `--bg-elevated`，奇偶**不做**斑马纹（深色下条纹干扰），改用 hover 高亮 |
| 行边框 | 底部 1px `--border-subtle` |
| hover | 背景 `--bg-hover` |
| 选中 | 背景 `--bg-active` + 左侧 2px `--accent` |

**特殊行状态**（原型大量使用）：

| 状态 | 表现 |
|---|---|
| 差异行（实体裁决） | 背景 `rgba(255,167,38,.08)`，文字 `--warn` |
| 异常行（空值率过高） | 数值文字 `--error`，加粗 |
| 过期行（知识包） | 整行 opacity .5 + 删除线 + 「扫描中自动排除」标签 |
| 告警行（案件包校验） | 背景 `rgba(255,167,38,.1)`，左侧 3px `--warn` |
| 拒绝单元格（权限矩阵） | **斜纹底 + 锁图标**，见 4.4 |

**关键实现**：TanStack Table 的 `meta.getRowClassName` 统一处理，不要在页面里散落写样式。

### 4.3 徽章 Badge

```
● 已核实        ← 圆点 + 文字，圆角 4px，高 20px
```

| 语义 | 底色 | 文字 |
|---|---|---|
| ok | `rgba(76,175,80,.15)` | `#81C784` |
| warn | `rgba(255,167,38,.15)` | `#FFB74D` |
| error | `rgba(255,82,82,.15)` | `#FF8A80` |
| info | `rgba(0,212,255,.12)` | `#4DD8FF` |
| filed | `rgba(255,179,0,.18)` | `#FFD54F` |

尺寸 20px 高，padding `0 8px`，圆角 4px，字号 11px，左侧 6px 圆点。

### 4.4 矩阵单元格 MatrixCell（权限矩阵专用）

**这是红线一的实现，三种状态必须视觉上不可混淆：**

| 状态 | 表现 |
|---|---|
| **可见** | 绿底 `rgba(76,175,80,.15)` + 对勾图标 |
| **遮蔽** | 橙黄半遮 `rgba(255,167,38,.15)` + 半圆图标 |
| **拒绝** | **深灰斜纹底** `repeating-linear-gradient(45deg, #1A2337, #1A2337 4px, #151D2E 4px, #151D2E 8px)` + 锁图标 + 文字「拒绝」 |

> **斜纹是刻意的**：纯色灰底容易被误认为"未配置/空白"，斜纹明确表达"此处有设定，设定是拒绝"。这条直接对应红线一的 E2E 断言。

### 4.5 按钮 Button

| 变体 | 背景 | 边框 | 文字 |
|---|---|---|---|
| primary | `--accent` | 无 | `#0A0E1A`（深色字，保证对比度） |
| secondary | 透明 | 1px `--border-default` | `--text-primary` |
| ghost | 透明 | 无 | `--text-secondary` |
| danger | `#FF5252` | 无 | `#FFF` |
| disabled | `--bg-hover` | 无 | `--text-disabled` |

尺寸：默认高 32px / padding `0 16px`；小号高 26px / padding `0 12px`。

**受控动作按钮**（如「立案」）：前缀锁图标，无权限时 disabled + Tooltip 说明原因。禁止用"点击后报错"代替禁用态。

### 4.6 表单控件

| 控件 | 默认 | 聚焦 | 错误 | 禁用 |
|---|---|---|---|---|
| Input | 背景 `--bg-base`，边框 `--border-default` | 边框 `--accent` + `box-shadow: 0 0 0 3px var(--accent-dim)` | 边框 `--error` + 下方 11px 红色提示 | 背景 `--bg-hover`，文字 `--text-disabled` |
| Switch | 轨道 `--bg-hover`，滑块 `--text-muted` | — | — | opacity .5 |
| Checkbox | 边框 `--border-strong` | 选中：背景 `--accent`，对勾深色 | — | 半选：横线 |

### 4.7 状态条 StatusBar（健康度）

```
┌────────────────────────────────────────────┐
│ ⚠ degraded   warning 2 · info 4   [详情]    │
└────────────────────────────────────────────┘
```

- 高度 48px，通栏，左侧 4px 语义色竖条
- 状态名 16px 600 字重，右侧计数徽章组
- **空链 / 零记录状态必须用 warn 语义，不得用 ok**（红线三）

### 4.8 时间线 Timeline（审计链）

- 竖线 1px `--border-default`，宽 2px
- 节点 10px 圆点，默认 `--text-muted`
- **节点间连接用链环小图标**（8px），暗示哈希链不可篡改——这是原型的视觉记忆点
- 已立案节点：金橙填充 + 2px 光晕 + 下方附法定依据文字
- 每个节点右侧标注本体版本号（11px mono 字体）

### 4.9 泳道卡片 KanbanCard（处置看板）

```
┌──────────────────────┐
│ 0.655  [资金][行为]    │  ← 分数 + 维度标签
│ 季度末整数现金存入      │  ← 14px 500
│ ────────────────────│
│ 王检察官 · 停留 3 天    │  ← 11px muted
└──────────────────────┘
```

- 宽度 100%（泳道自适应），padding 12px，圆角 6px
- 左侧 3px 竖条：正常 `--accent`，超期 `--error`，已立案 `--filed`
- **超期时整卡红框** `border: 1px solid var(--error)`
- 拖拽中：opacity .6 + `box-shadow` 加强

### 4.10 骨架屏 Skeleton

- 背景 `linear-gradient(90deg, #1A2337 25%, #223050 50%, #1A2337 75%)`，1.2s 循环
- 形状贴合真实内容（表格行用矩形条，卡片用矩形块）
- **禁止 spinner + 空白**——与"消除留白"原则冲突

### 4.11 空态 EmptyState

三类必须区分，**这是最容易被合并的设计错误**：

| 类型 | 图标 | 文案 | 动作 |
|---|---|---|---|
| 真的没有 | 空盒 | 「暂无数据」+ 说明 | 有引导按钮 |
| 被权限挡住 | 锁 | 「无访问权限」 | 申请入口 |
| 出错了 | 警告 | 「加载失败」+ 原因 | 重试按钮 |

> 把"无权限"画成"暂无数据"会让用户推断出"这个资源存在但我不该看"，构成信息泄漏。

## 五、图表主题（ECharts）

注册统一深色主题，**所有图表共用**：

```js
echarts.registerTheme('sunwu-dark', {
  backgroundColor: 'transparent',
  textStyle: { fontFamily: 'Noto Sans SC', fontSize: 12, color: '#8B9BB4' },
  color: ['#00D4FF', '#FFB300', '#B388FF', '#4CAF50', '#FF7043', '#FF5252'],
  // 环形图（治理仪表盘双环）
  // 热力图（庙算五间枚举）——visualMap 用 accent 单色渐变
  // 堆叠条（等级分布）——用五间色
});
```

| 图表 | 页面 | 要点 |
|---|---|---|
| 双环形 | 01 仪表盘 | 声明/实证两个环**并排不合并**；中心显示百分比 |
| 热力图 | 11 庙算 | visualMap 用 `--accent` 单色渐变，未覆盖格用 `--bg-hover` |
| 堆叠条 | 01 仪表盘 | 等级分布用语义色，非五间色 |
| 柱状图 | 03/17 | 历史命中、触发统计 |

ECharts 6 支持 `chart.setTheme()` 动态切换，密度切换时可联动。

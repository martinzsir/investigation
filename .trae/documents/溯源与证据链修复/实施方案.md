## B1：服务端溯源行适配器

**新建** `server/app/source_row_dto.py`

### 职责

URI → 溯源面板字段表（含中文名、hit 标记、遮蔽策略）。

### 接口

```python
def resolve_source_row(
    *, uri: str, conn, pack_id: str,
    access: AccessContext, base_dir: Path,
    hit_fields: list[str] | None = None,
) -> dict | None:
    """解析行 URI → 溯源面板字段表。

    返回 None 表示 URI 对应行已不在此版本（跨版本场景，RowNotFoundError）。
    """
```

### 实现流程

```
1. parse_row_uri(uri) → {dataset, version, partition, rowid}
2. 按 dataset 查 bindings.json source_table → 对应 obj_* 表
3. 查 objects.json 得属性列表 + 中文名映射
   （属性名 → data_elements.json 中文名，回落列名）
4. SELECT * FROM row_archive WHERE rowid = ?
   （或回落 SELECT * FROM obj_<table> WHERE rowid = ?）
5. 逐字段套 policies.json 策略 + access.role：
   - role 命中 allow_roles → visible（原文）
   - mask=partial → masked（maskPhone/maskIdCard/通用****）
   - 其余 → denied（****）
   - 未在 policies 声明的属性一律 denied（fail-closed）
6. hit_fields 标记（来自 rules.json params 或调用方传入）
```

### 返回结构

```python
{
    "dataset": "通话记录",
    "build_id": "v3",
    "rowid": "8f3a21",
    "partition": "p0",
    "fields": [
        {"name": "主叫", "raw": "caller_raw", "value": "张卫国", "hit": false, "policy": "visible"},
        {"name": "通话次数", "raw": "call_count", "value": "12", "hit": true, "policy": "visible"},
        {"name": "对方手机号", "raw": "phone", "value": "138****5678", "hit": false, "policy": "masked"},
        {"name": "涉密备注", "raw": "secret_note", "value": "****", "hit": false, "policy": "denied"},
    ]
}
```

### 关键约束

- **遮蔽必须在服务端做**（红线 FE-T-021：明文不入缓存）
- `hit_fields` 来源：从线索 artifact 的 `detail.params` 或 rules.json 的命中字段声明提取
- 未声明属性 = denied（fail-closed，与前端 `maskField` 同口径）
- `row_archive` 表不存在时回落 `obj_*` 表（旧版本兼容）

## B2：证据三栏产出器

**新建** `server/app/evidence_builder.py`

### 职责

线索 raw artifact → `EvidenceItem[]`（前端 `partitionEvidence` 直接消费）。

### 接口

```python
def build_evidence(
    *, raw_clue: dict, conn, pack_id: str,
    access: AccessContext, base_dir: Path,
) -> list[dict]:
    """产出 EvidenceItem 列表（fact/inference/pending）。"""
```

### 三栏产出规则

#### 事实栏（fact，§1 方案 B 按行聚合）

```
输入：raw_clue["detail"]["pairs"]（R3 Function 返回的 pairs）
      = [{"主体": "张卫国", "对端": "李志强", "次数": 12}, ...]
产出：每行一条 EvidenceItem
      id = f"f{rule_id}-{idx}"
      kind = "fact"
      text = f"主叫 {主体} · 被叫 {对端} · 通话次数 {次数}"
      source_rows = [{"row_uri": <raw_clue.source_rows[idx]>}]
```

- `pairs` 缺失时回落 `raw_clue["source_rows"]` 逐行生成
- 每条事实的 `source_rows` 与 raw artifact 的 `source_rows` 一一对应

#### 推断栏（inference）

```
输入：raw_clue["basis"]（Function 返回的判据文本）
产出：
  id = f"i{rule_id}"
  kind = "inference"
  text = basis  # "张卫国→李志强 通话 12 次，为常态中位数 3 的 4.0 倍"
  source_rows = raw_clue["source_rows"]  # 全部溯源行
```

- **无 source\_rows 的推断被丢弃**（前端 partitionEvidence 已实现，计 droppedInferences）
- 推断栏颜色固定琥珀（前端已硬编码）

#### 待核实栏（pending，§3 方案 A 最小集）

```
输入：raw_clue["detail"]["diagnostics"]
产出：
  1. 假设条目（hypotheses.json 匹配 rule_id → "待验证假设：H3（公示期异常沟通）"）
  2. 降级标记（diagnostics.is_degraded → "判据已降级：{degrade_reason}"）
```

- 无降级时不产出降级条目（本例有 2 个对端，不触发降级）
- 假设条目从 `core/hypotheses.py` 的 HYPOTHESES 按 rule\_id 匹配

### 关键约束

- 推断栏文本不得含定性措辞（"涉嫌/确认/串标"等，红线 #7）
- `basis` 是 Function 确定性产出的中性文本，直接透传不改写
- 事实栏内容只来自原始数据字段，不混入推断（红线 #1 物理分隔）

## B4：实体裁决审计链 bug 修复

### 问题

[server/app/worker/review.py](file:///d:/dev/inves_duckdb/server/app/worker/review.py) L91 调 `sink.audit_append({...})`，但 `StateSink`（[state\_sink.py](file:///d:/dev/inves_duckdb/server/app/store/state_sink.py) L60-94）**无此方法**——会抛 `AttributeError`。

由于 `review_decision` 表 0 行（未触发过实体裁决），此 bug 未被暴露。

### 修复

在 `StateSink` 补 `audit_append` 方法：

```python
# server/app/store/state_sink.py StateSink 类内新增

def audit_append(self, detail: dict) -> str | None:
    """追加审计链事件（Worker 裁决/处置后调用）。

    detail 至少含 event/operator/ontology_version；
    before/after 由调用方按语义填充。
    """
    from core.audit import AuditChain
    chain = AuditChain(
        self._state.conn, case_id=self.case_id,
        backend="sqlite",
        ontology_version=self.ontology_version)
    return chain.append(
        operator=detail.get("operator", ""),
        before=detail.get("before"),
        after=detail,
        source_row_ids=detail.get("source_row_ids", []),
        ontology_version=self.ontology_version)
```
